📝 ERPD (Eternal Return Pixel Dungeon) 기획서
버전: v0.1.0 (각성 시스템 도입안)
핵심 요약: 녹픽던(SPD)의 기존 전직 시스템을 완벽하게 재활용하여, '미상의 생존자'가 루미아 섬의 가혹한 환경을 뚫고 본래의 '실험체(정체)'로 각성하는 서사적 카타르시스를 제공한다.

1. 핵심 기획 방향: "정체 숨김 ➡️ 각성(전직)"
초기부터 특정 실험체를 고르고 시작하는 방식의 기술적/아트적 한계를 극복하기 위해, 스토리텔링과 로그라이크식 성장을 결합한 새로운 구조를 채택한다.

1단계 (1층 ~ 9층) - 미상의 생존자:

플레이어는 '후드를 쓰거나 마스크를 쓴 미상의 생존자(전사, 도적, 마법사 등)'로 던전에 진입한다.

이 시점에서는 고유 패시브나 화려한 스킬 없이, 기본적인 생존 능력과 낡은 무기(예: 닳은 목장갑)만으로 난관을 헤쳐 나간다.

장점: 초반 밸런스 조절이 쉽고, 공용 스프라이트를 사용하여 도트 작업량을 획기적으로 줄임.

2단계 (10층 보스 처치 후) - 실험체 각성 (정체 공개):

10층 텐구(보스) 처치 후 '전직의 서'를 읽는 순간, 숨겨왔던 정체가 드러난다.

후드/마스크를 벗어던지며 이타널 리턴의 고유 실험체(현우, 히스이 등)로 외형(스프라이트/초상화)이 변경된다.

이때부터 해당 실험체의 텍스트가 출력되며, 강력한 고유 패시브(예: 도그파이트)가 해금된다.

2. 캐릭터 분기 및 시스템 매칭
현재 가장 먼저 개발 중인 '전사(Warrior)' 직업군의 매칭 트리입니다.

🛡️ 베이스 클래스: 후드를 쓴 전사 (Warrior)
외형: 낡은 튜닉과 후드를 뒤집어쓴 묵묵한 생존자.

특징: 근접 전투에 능하며, 기본적인 스탯을 보유. (기존 SPD 전사와 동일)

💥 전직 A: 광전사 (Berserker) ➡️ 현우
컨셉: 적과 난타전을 벌일수록 맷집과 회복력이 괴물처럼 변하는 '후반 왕귀형 인파이터'.

핵심 메커니즘 개조 (도그파이트 영구 스택형):

기존 SPD 광전사의 '피가 깎일수록 데미지 증가(분노)' 로직은 삭제(비활성화)한다.

무한 성장형 도그파이트: 적과 싸워 도그파이트 스택(10스택)을 터트릴 때마다 totalDogfightTriggered (총 발동 횟수) 변수가 1씩 영구 증가한다.

이 영구 스택이 쌓일수록 현우의 기본 방어력이나 도그파이트 발동 시의 회복량이 영구적으로 상승한다.

외형 변화: 후드를 벗고 붉은 머리와 주름진 갈색 교복을 드러낸다.

⚔️ 전직 B: 검투사 (Gladiator) ➡️ 히스이 (또는 기타 실험체)
컨셉: 연속된 타격(콤보)을 통해 강력한 특수 스킬(무기 기술)을 연계하는 테크니컬 근접 딜러.

핵심 메커니즘 개조:

기존 SPD 검투사의 '콤보 스택' 시스템을 그대로 활용.

콤보 스킬들의 이름을 이터널 리턴/히스이의 컨셉에 맞게 텍스트 폴리싱.

3. 이 기획의 압도적인 이점 (개발 공학적 측면)
이 구조는 1인 인디 개발(특히 사지방 환경)에서 프로젝트 성공률을 극적으로 높이는 최고의 선택입니다.

UI 엔진 무임승차 (개발 난이도 하락):

게임을 시작할 때 실험체를 고르는 팝업 UI를 바닥부터 만들 필요가 없다. 이미 100% 완벽하게 작동하는 원본의 '10층 전직 UI'를 그대로 가져다 이름만 텍스트 파일(messages_ko.properties)에서 바꿔치기하면 된다.

아트 리소스(도트) 병목 해결:

기본 캐릭터들(전사, 마법사, 도적)의 1~9층 도트를 공용(후드)으로 1개씩만 찍어두면 된다. 개발자는 오직 힘을 줘야 할 '전직 후 실험체 픽셀 아트'에만 시간을 쏟을 수 있다.

코드 안정성과 세이브 파일 관리:

엔진 내부에서는 여전히 HeroSubClass.BERSERKER, HeroSubClass.GLADIATOR라는 기본 식별자를 사용하므로, 게임이 터지거나 세이브 파일이 박살 날 위험이 거의 없다.

4. 🚀 향후 개발 마일스톤 (Action Plan)

[ ] Step 2: 광전사의 원본 패시브인 분노(Rage) 코드를 찾아 주석 처리(//).

[ ] Step 4: 영구 스택 수치에 비례하여 방어력 또는 회복량을 증가시키는 공식 추가.
